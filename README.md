# 🌱 EcoTrack – Smart Campus Waste Management System

EcoTrack is a web-based smart waste management system designed to improve waste reporting, classification, and tracking on campus. It provides students with an easy way to report waste and allows administrators to monitor and manage waste reports through a dashboard.

## 🚀 Features

- 👨‍🎓 Student Login
- 👨‍💼 Admin Login
- 📝 Report Waste
- 📍 Select Waste Location
- 📸 Upload Waste Images
- ♻️ Waste Classification
- 📊 Admin Dashboard
- 📋 Track Waste Reports
- 🔄 Manage Report Status
- 🌱 Promote Sustainable Waste Management

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## 🔄 How EcoTrack Works

1. The student logs into the EcoTrack system.
2. The student reports waste by providing its type, location, description, and image.
3. The system processes and classifies the reported waste.
4. The report is stored and displayed on the dashboard.
5. The administrator can view and manage submitted reports.
6. The report status can be updated as the waste is handled.

## 💡 Problem Statement

Improper waste disposal and the lack of an organized reporting system can make campus waste management difficult. EcoTrack provides a digital platform where students can report waste and administrators can monitor and manage these reports efficiently.

Our vision is to create a cleaner, smarter, and more sustainable campus by using technology to encourage responsible waste management and student participation.
